# Scientific Calculator (Python Project)

A command-line based Scientific Calculator built using Python.

This project supports both basic arithmetic operations and advanced mathematical calculations such as powers and roots.

The calculator continuously performs operations until the user chooses to exit.

---

## 📌 Project Overview

The calculator allows users to:

### Features:
- Addition
- Subtraction
- Multiplication
- Division
- Power Calculation
- Nth Root Calculation
- Continuous calculations using previous result
- Error handling for invalid inputs and division by zero

The project is designed to strengthen logic-building and problem-solving skills using Python.

---

## 🛠 Concepts Used

- Functions
- Loops (`while`)
- Conditional Statements
- Exception Handling (`try-except`)
- Python `math` module
- User Input Handling

---

## ▶️ How to Run

1. Install Python
2. Download the project file
3. Run the program using terminal:

```bash
python calculator.py
```
